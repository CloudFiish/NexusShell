## 2. 🔄 架构方案：ACP + Python SDK

采用官方推荐的 **Python SDK** 作为中间层，通过 stdio 与 Rust 后端通信。

### 数据流
```
[Frontend UI] <-> [Tauri Bridge] <-> [Rust Adapter] <-> [Python Bridge] <-> [CodeBuddy SDK] <-> [CLI]
```

*   **Rust Adapter**: 管理 Python 子进程，通过 stdio 收发 JSON。
*   **Python Bridge**: 使用 `codebuddy-agent-sdk` 调用底层 CLI，处理协议转换。
*   **Frontend**: 解析 `ContentBlock` 结构，实现富文本和工具调用的渲染。
