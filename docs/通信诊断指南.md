# CodeBuddy 通信诊断指南

## 概述

本文档介绍如何在前端检查与 CodeBuddy SDK 的通信状态。

## 诊断工具

### 1. 状态栏指示器

状态栏现在集成了通信状态显示：

- **Agent 状态指示灯**：显示 Agent 运行状态
  - 🟢 绿色：Agent 运行中
  - 🟡 黄色：Agent 启动中
  - 🔴 红色：Agent 出错或未运行

- **事件计数**：显示收到的事件数量

- **延迟显示**：显示最后一次端到端测试的延迟

- **诊断按钮**：点击状态栏右侧的图表图标可运行快速诊断

### 2. 通信诊断组件

`CommunicationDiagnostics.vue` 组件提供了详细的诊断信息：

```vue
<template>
  <CommunicationDiagnostics />
</template>

<script setup>
import CommunicationDiagnostics from '@/components/CommunicationDiagnostics.vue'
</script>
```

### 3. 诊断 Composable

`useCommunicationDiagnostics.ts` 提供了编程接口：

```typescript
import { useCommunicationDiagnostics } from '@/composables/useCommunicationDiagnostics'

const {
  // 状态
  diagnosticsResults,
  isRunningDiagnostics,
  communicationStatus,

  // 方法
  checkAgentStatus,
  checkEventSystem,
  checkSessionSystem,
  testEndToEndCommunication,
  runFullDiagnostics,
  startAgentAndWait,
  getStatusSummary,
  clearResults,
  cleanup
} = useCommunicationDiagnostics()
```

## 诊断项目

### 1. Agent 状态检查

检查 Agent 是否正在运行：

```typescript
const result = await checkAgentStatus()
// 结果示例：
// { success: true, stage: 'Agent', message: 'Agent 正在运行', ... }
```

### 2. 事件系统检查

检查事件监听器是否正常工作：

```typescript
const result = await checkEventSystem()
// 结果示例：
// { success: true, stage: 'EventSystem', message: '事件监听器已激活', ... }
```

### 3. 会话系统检查

检查会话存储状态：

```typescript
const result = await checkSessionSystem()
// 结果示例：
// { success: true, stage: 'SessionSystem', message: '会话系统正常', ... }
```

### 4. 端到端通信测试

执行完整的通信测试：

```typescript
const result = await testEndToEndCommunication()
// 结果示例：
// { success: true, stage: 'EndToEnd', message: '端到端通信测试成功', ... }
```

## 故障排除

### 问题 1：Agent 未运行

**症状**：状态栏显示 "Offline" 或 "Error"

**解决方案**：
1. 点击状态栏左侧的 Agent 名称启动 Agent
2. 或者使用诊断组件中的 "启动 Agent" 按钮
3. 检查控制台日志获取详细错误信息

### 问题 2：事件未收到

**症状**：Agent 运行中但事件计数为 0

**解决方案**：
1. 执行一个 Skill 来触发事件
2. 检查浏览器控制台是否有错误
3. 运行完整诊断查看详细日志

### 问题 3：端到端测试失败

**症状**：延迟显示为 "--" 或测试超时

**解决方案**：
1. 检查 API 密钥配置
2. 检查网络连接
3. 查看诊断日志中的详细错误信息

## 调试技巧

### 1. 查看浏览器控制台

所有诊断信息都会输出到浏览器控制台：

```
[Diagnostics] ✅ [Agent] Agent 正在运行
[Diagnostics] ✅ [EventSystem] 事件监听器已激活
[Diagnostics] ❌ [EndToEnd] 端到端通信测试失败
```

### 2. 使用诊断日志

诊断结果会保存到 `diagnosticsResults` 数组中，可以查看详细的错误信息：

```typescript
console.log(diagnosticsResults.value)
```

## 集成到现有组件

### 在 OmniBox 中显示诊断状态

```vue
<script setup>
import { useCommunicationDiagnostics } from '@/composables/useCommunicationDiagnostics'

const { communicationStatus } = useCommunicationDiagnostics()
</script>

<template>
  <div>
    <span v-if="communicationStatus.agentRunning" class="text-green-400">
      ● Agent 就绪
    </span>
    <span v-else class="text-red-400">
      ● Agent 未运行
    </span>
  </div>
</template>
```

### 在发送消息前检查通信状态

```typescript
async function sendMessage() {
  const { communicationStatus, runFullDiagnostics } = useCommunicationDiagnostics()

  if (!communicationStatus.value.agentRunning) {
    // 尝试启动 Agent
    const result = await startAgentAndWait()
    if (!result.success) {
      alert('无法启动 Agent: ' + result.message)
      return
    }
  }

  // 发送消息...
}
```

## 注意事项

1. **诊断会消耗 API 配额**：端到端测试会实际调用 CodeBuddy API
2. **事件监听是全局的**：一个页面只需要一个事件监听器
3. **及时清理资源**：组件卸载时调用 `cleanup()` 清理事件监听
